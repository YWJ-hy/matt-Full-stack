# 体验需求 · 客服领取工单

我是值班客服。现在工单台能看到待处理的工单，我希望能在列表中领取一张工单，让同事看到谁在跟进。

| 场景 | 我希望看到的结果 |
|---|---|
| CLAIM-01 领取 | 我以「体验客服」登录。`QA-101 更换收货地址` 显示「待领取」。点击这张工单的「领取」后，它显示「处理中 · 体验客服」。 |
| CLAIM-02 刷新 | 在同一次服务运行期间刷新页面，`QA-101` 仍归体验客服，页面再次打开也能从服务端读回该状态。 |
| CLAIM-03 已被领取 | `QA-102 查询退款进度` 已归客服乙。列表只给待领取工单提供领取操作。两个窗口先后领取同一张工单时，后来的请求得到「工单已被领取」提示，原处理人保持不变。 |
| CLAIM-04 未登录 | 没有有效体验会话时尝试领取，服务返回 401，工单仍可由已登录客服领取。 |

请父会话自行定位页面和接口，拟定领取契约、约定各端的测试边界，把可观察结果写入公共 spec 和业务 YAML。分别派发前后端，各端交回测试、审查结果和版本。最后用真实浏览器连接本机测试后端验收，失败按责任端回派。基线用例 `BASE-01` 可以在开发前运行。

本轮使用两张合成工单，重启后端即可重置数据。完成时请给我展示领取前后、刷新后的结果，以及各场景的验收记录。
